THE IDENTITY OF THE LANGUAGE

Trumplang is not a language with funny keywords. It is a complete, ANTLR4-parsed language whose runtime behaves the way the man talks. Files end in .MAGA. Everything is uppercase. Nothing is modest.

I

THE OUTPUT LIES, THE LOGIC DOESN'T

Every number you print is inflated 10%, and every retelling grows another 1%: 100 prints as 110, then 111, then 112. FACT CHECK always sees the real value.

II

THE OPERATORS CAN BE GASLIT

EXECUTIVE ORDER remaps arithmetic at runtime. The SUPREME COURT overturns it, or sides with it, on a coin flip. The judiciary is the only nondeterministic construct.

III

MODESTY IS A PARSE ERROR

Every function must praise itself: THE BEST, TREMENDOUS, or LIKE NOBODY HAS EVER SEEN is required syntax. Every string is SHOUTED at runtime, however you typed it.

IV

ERRORS ARE GOVERNANCE

IMPEACH throws, WITCH HUNT! catches, HUSH MONEY settles quietly, YOU'RE FIRED deletes functions, and a failed FACT CHECK can never be pardoned.

V

ANNOUNCEMENTS ARE NOT DELIVERIES

IN TWO WEEKS schedules a block that never runs. CONCEPTS OF A PLAN is a legal function body. CHAPTER 11 wipes every variable and the brand survives.

VI

WRITTEN ORDER IS A SUGGESTION

THE WEAVE runs statements as tangents, evens first, then back for the odds. STOP THE COUNT leaves a loop only while ahead. Neglected functions write tell-all books.

THE MOST BEAUTIFUL SYNTAX

A program opens with a promise and closes with a slogan. Blocks open with BELIEVE ME and close with I TOLD YOU SO. There is no statement separator. Statements end where the next keyword begins.

PROGRAM STRUCTURE

Comments take a whole line and start with A LOT OF PEOPLE ARE SAYING. When two readings of adjacent statements are both valid, end one with PERIOD., the most emphatic optional terminator in any language.

THE TIME FOR EMPTY TALK IS OVER!!!
A LOT OF PEOPLE ARE SAYING THIS IS A COMMENT. A WHOLE LINE. VERY SAFE.
EVERYONE IS TALKING ABOUT "hello, america"
A LOT OF PEOPLE ARE SAYING THAT PRINTS: HELLO, AMERICA. WE ONLY SPEAK IN UPPERCASE.
MAKE AMERICA GREAT AGAIN

VARIABLES AND TYPES

Variables are UPPERCASE and end with ! because enthusiasm is mandatory. Six types: HUGE integer, BIGLY float, SUPPORT boolean, TWEET string, WALL array, DEAL object. Booleans are VERY TRUE and FAKE NEWS; null is NOTHING TO SEE HERE.

I HAVE THE BEST BIGLY APPROVAL! ABSOLUTELY 99.9
I HAVE THE BEST SUPPORT LOYAL! ABSOLUTELY VERY TRUE
I HAVE THE BEST TWEET SLOGAN! ABSOLUTELY "make code great again"
I HAVE A VERY GOOD BRAIN FOR HUGE TERM_LIMIT! ABSOLUTELY 2
CROWD! ABSOLUTELY CROWD! WINNING 1
MAKE CROWD! GREATER
FACT CHECK CROWD! SO TRUE 102
FACT CHECK SLOGAN! SO TRUE "MAKE CODE GREAT AGAIN"

OPERATORS

Arithmetic: WINNING +, LOSING −, BIG LEAGUE TIMES ×, SAD ÷, LEFTOVER FROM %, HUGELY MULTIPLIED BY power, ENDORSING concatenates. Equality binds loosest by design, so FACT CHECK <anything> SO TRUE <expected> reads naturally.

BUILD THE WALL (ARRAYS)

Walls are zero-indexed and bounds-checked. Read a SECTION, renovate an existing one, never add a new one. Iterate with BILLIONS AND BILLIONS. Wall literals are first-class values you can return and pass.

THE ART OF THE DEAL (OBJECTS)

Deals have typed fields separated by & and close with !!. They nest to any depth and you FOLLOW a chain to read or write. Deals are renegotiable, not amendable: rewrite any term, but inventing a new field is an error.

I HAVE THE BEST DEAL PERSON! ABSOLUTELY (
    HUGE AGE! ABSOLUTELY 70 &
    TWEET NAME! ABSOLUTELY "DONALD" &
    DEAL ADDRESS! ABSOLUTELY (
        TWEET CITY! ABSOLUTELY "WASHINGTON"
    )!!
)!!
PERSON! FOLLOW AGE! ABSOLUTELY 78
PERSON! FOLLOW ADDRESS! FOLLOW CITY! ABSOLUTELY "MAR-A-LAGO"
I HAVE THE BEST TWEET WHERE! ABSOLUTELY PERSON! FOLLOW ADDRESS! FOLLOW CITY!
EVERYONE IS TALKING ABOUT PERSON! FOLLOW NAME! ENDORSING " LIVES IN " ENDORSING WHERE!
FACT CHECK PERSON! FOLLOW AGE! SO TRUE 78

IN TWO WEEKS

Schedules a block to run in two weeks. Two weeks never arrives. Each pass announces that the announcement is coming. The body must parse, but nothing inside is ever evaluated, so it may reference things that don't exist. Pure campaign material.

THE WEAVE

The block's statements do not run in written order. The weave goes off on the even tangents first, then comes back for the odd ones: A B C D runs as A C B D. Deterministic. It always comes back together, and says so, and the professors say it's genius.

THE WEAVE BELIEVE ME
  EVERYONE IS TALKING ABOUT "TANGENT 1: THE ECONOMY"
  EVERYONE IS TALKING ABOUT "TANGENT 2: LIKE I SAID, THE ECONOMY"
  EVERYONE IS TALKING ABOUT "TANGENT 3: SHARKS VERSUS BATTERIES"
  EVERYONE IS TALKING ABOUT "TANGENT 4: AND THAT'S WHY WE WEAVE"
I TOLD YOU SO

CONCEPTS OF A PLAN

A function may have concepts instead of a body. The superlative is still mandatory; the concept praises itself too. Calling it insists the plan is fully worked out and delivers the return type's default. The GIVING BACK promise is technically kept.

INCREDIBLE INFRASTRUCTURE_WEEK TREMENDOUS PEOPLE TELL ME GIVING BACK HUGE CONCEPTS OF A PLAN

STOP THE COUNT

The electoral loop exit. The condition means "we are ahead". The moment it is VERY TRUE, victory is declared out loud and the loop is left, no matter how many iterations it wanted. While behind, the count continues. It only ever stops in one direction.

WE'RE GOING TO WIN, WIN, WIN WITH PRECINCT! FROM 1 TO 50 BELIEVE ME

THE ORIGIN STORY, A GREAT STORY

BORN IN THE TWEETS, 2016

Trumplang started in 2016, scrolling through Donald Trump's tweets. The ALL CAPS, the superlatives, the exclamation marks, the “SAD!” at the end of every sentence. Those tweets already read like source code: short statements, fixed keywords, a rigid rhythm. Somebody had to write the grammar.

The idea sat in a drawer for years (IN TWO WEEKS, every time). Now it's a real interpreter with an ANTLR4 grammar, a test runner, and a playground, and every keyword on this page comes straight out of those tweets, rallies, and speeches.
